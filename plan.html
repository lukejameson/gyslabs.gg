Fix local development setup so index.html loads correctly with Live Server without breaking the production Docker build.
Progress6 / 6

💡 Why & How

The site is a static HTML site. Two issues prevent local dev:
1. tailwind.css is only generated during Docker build, not locally
2. ${UMAMI_URL}/${UMAMI_TRACKING_ID} placeholders are substituted by envsubst only in Docker. Locally, the browser tries to fetch these as literal URLs, causing NS_ERROR_CORRUPTED_CONTENT + MIME type mismatch errors that block all styles from loading.

Fix: install Tailwind CSS + generate the CSS file locally; replace the Umami script tag with JS that gracefully skips when placeholders aren't substituted.

🎁 Expected Outcome

Run npm run build:css && npm run build then open with Live Server — no CSS or script loading errors. Docker build continues to work unchanged.
